# 大喜利練習アプリ

`odai.json`（過去の大喜利ファイルから抽出したお題 2,266問 / 回答 19,037件）から
お題をランダムに出題し、自分で回答を書いたあとに「ファイルにあった答え」を見比べる
ローカル実行の練習アプリ。仕様は `大喜利アプリ_仕様書.md`。

## 起動

```
pip install -r requirements.txt
python app.py
```

→ http://localhost:5000

## 使い方

- 上部の **出典フィルタ** でお題の出どころを絞る。既定は「茶屋を除く」（茶屋は
  全体の91%を占める短文スタイルのため）。
- 回答を書いて **回答する**（`Ctrl/Cmd + Enter`）。押すまでファイルの答えは見えない。
- 書かずに次へ行くなら **パス**（`→`）。パス・回答済みのお題は同じセッション中に再出題されない。
- 回答するたび `history.jsonl` に1行追記される（閲覧UIは無し）。

## お題データの再生成

元ファイルを更新したら:

```
python extract_odai.py <お題ファイルのあるフォルダ> -o odai.json
```

`ハシリドコロ_大喜利理論_1 / _2` は自動で除外される（お題ではなく講評の評価軸に使う）。

## 構成

| ファイル | 中身 |
|---|---|
| `app.py` | Flask バックエンド（1ファイル） |
| `templates/index.html` | フロント（素の HTML + JS 1枚・ビルド不要） |
| `odai.json` | 抽出済みお題データ |
| `extract_odai.py` | `odai.json` の生成スクリプト |
| `ハシリドコロ_大喜利理論_1.txt` / `_2.txt` | 講評の評価軸に使う理論文書 |
| `history.jsonl` | 回答ログ（実行時に生成・gitignore） |

## API

| エンドポイント | 中身 |
|---|---|
| `GET /api/odai?exclude=茶屋` | ランダムなお題1問（`answers` は返さない） |
| `GET /api/odai/<id>/answers` | そのお題の答え |
| `POST /api/history` | `{odai_id, answer}` を `history.jsonl` に追記 |
| `GET /api/sources` | 出典一覧（件数付き） |
| `POST /api/reset` | 出題済みの記録をクリア |
